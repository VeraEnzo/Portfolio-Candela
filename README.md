# Portfolio Candela Merás

Portfolio personal de **Candela Merás**, diseñadora de indumentaria argentina y fundadora de la marca **Meiri Doll**.

## Sobre el sitio

Sitio web estático de una sola página construido con HTML, CSS y JavaScript vanilla — sin frameworks ni dependencias. Presenta el trabajo de Candela en tres proyectos principales:

- **Marie's Dollhouse** — Colección de egreso de la facultad
- **Meiri Doll** — Marca propia de indumentaria femenina
- **Taller & Proceso** — Piezas de taller y proceso creativo

## Tecnologías

- HTML5 / CSS3 / JavaScript (vanilla)
- Google Fonts: Playfair Display, Cormorant Garamond, Great Vibes, Jost
- Sin build system ni dependencias npm

## Correr localmente

```bash
# Python
python -m http.server 8000

# Node.js
npx http-server
```

O simplemente abrir `index.html` en el navegador.

## Estructura

```
Portfolio-Candela/
└── index.html    # Todo el sitio: HTML + CSS + JS en un solo archivo
```
